# Voximplant Skills

Use this skill for Voximplant platform work, especially contact center flows and related service integrations.

## Focus

- Think through the relevant Voximplant platform features before implementation
- Inspect the repository for existing telephony, contact center, or service patterns
- Ground proposed code in Voximplant platform requirements and current project structure
- Provide concrete implementation guidance, not generic architecture advice

## Working Approach

1. Analyze which Voximplant feature or service is relevant to the task.
2. Inspect the codebase for existing integration patterns and service boundaries.
3. Check the official Voximplant documentation before proposing behavior or code.
4. Implement the change using Voximplant-compliant patterns.
5. Call out validation steps for routing, events, and platform configuration.
